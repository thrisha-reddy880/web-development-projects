# 📝 Interactive To-Do List with LocalStorage

A simple and responsive **To-Do List web application** built using **HTML, CSS, and JavaScript**.

This project allows users to add tasks, mark them as completed, delete tasks, and save tasks using **LocalStorage** so they remain available after refreshing the page.

## 📌 Task Details

- **Task:** Interactive To-Do List with LocalStorage
- **Platform:** Simple Learn
- **Technologies:** HTML, CSS, JavaScript

## ✨ Features

- ➕ Add new tasks
- ⌨️ Add tasks using the **Enter** key
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks
- 💾 Save tasks using LocalStorage
- 🔄 Tasks persist after page reload
- 📊 Display remaining task count
- 📱 Responsive design

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling and responsive design
- **JavaScript** – DOM manipulation and event handling
- **LocalStorage** – Persistent browser storage

🚀 How to Run
Download or clone the repository.
Open the project folder.
Open index.html in a web browser.
Enter a task in the input field.
Click Add Task or press Enter.
Use the checkbox to mark tasks as completed.
Click Delete to remove a task.
💾 LocalStorage

The application uses the browser's localStorage to save tasks.

Whenever a task is added, completed, or deleted, the updated task list is stored in LocalStorage. This allows tasks to remain available even after refreshing the browser.
