## 📌 Project Overview

The **Responsive Product Pricing Cards** project is a frontend-based SaaS pricing interface that allows users to explore different subscription plans.

Users can switch between **Monthly** and **Yearly** billing using an interactive toggle. The displayed prices automatically update using JavaScript.

The project focuses on creating a clean, modern, responsive, and interactive pricing interface.

# 🎨 UI Design

The interface follows a modern **SaaS pricing page design** with a clean and professional visual style.

### Design Elements

- Clean pricing cards
- Rounded corners
- Soft shadows
- Modern typography
- Clear pricing hierarchy
- Interactive buttons
- Monthly/Yearly toggle
- Highlighted pricing plans
- Popular and Best Value ribbons
- Smooth hover animations
- Balanced spacing and alignment

### Color and Visual Style

The design uses a light background with white pricing cards and purple accent elements.

The purple accent is used for:

- Primary buttons
- Toggle switch
- Popular badge
- Card borders
- Interactive elements

The design keeps the interface simple and easy to understand.
