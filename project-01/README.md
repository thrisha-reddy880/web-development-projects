# K. Thrisha Reddy — Final Portfolio

A responsive, interactive portfolio inspired by the supplied reference portfolio, rebuilt with Thrisha's own information and uploaded certificate assets.

## Included
- Interactive 3D profile-card tilt
- Responsive glassmorphism design
- About, Education, Skills, Projects, Achievements, Experience
- Certificate gallery with category filters
- Full-screen certificate preview modal
- GitHub + LinkedIn links
- Mobile responsive layout

## Before publishing
Open `index.html` and replace every occurrence of:
`YOUR_EMAIL@example.com`
with the email address you want to display.

## Run
Simply open `index.html` in a modern browser. No build step is required.
